goal_lvl_dv_data primary

The dependent variable. One row per country-year-goal, carrying every outcome measure side by side so you switch measures without switching datasets. Use raw counts with fixed effects for causal work; the _pct_ columns for cross-goal descriptive comparison. Two scopes stacked (see scope): the 17-goal panel plus a country-year total.

raw_data source

The source of truth — one row per observation (country × series × year × disaggregation). Every dataset above derives from it. You filter it to build custom cuts, but you don't model on it directly.
