# Not deposited — superseded by v1.2.0

This bundle was assembled on 8 November 2026 for the 524-series variant
collapse and **was never deposited to Zenodo**. It has no version DOI, and
nothing cites it.

The sector layer (`goal_level`) landed the following day, so the 524 change and
the sector layer were deposited together as **v1.2.0**. Everything in this
directory is contained in `releases/v1.2.0/`, which supersedes it.

The directory is kept as a record of what was built, not as a release. Zenodo
does not require contiguous version numbers, so the jump from 1.0.0 to 1.2.0
is intentional and affects nothing.
