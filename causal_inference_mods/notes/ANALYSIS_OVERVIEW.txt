
================================================================================
                         ANALYSIS OVERVIEW
        Democratic Backsliding & Data Availability Analysis
================================================================================

YOUR RESEARCH QUESTION:
How do changes in democracy scores affect countries' data availability?

Specifically: Does democratic BACKSLIDING increase data missingness 
differently than DEMOCRATIZATION decreases it?

================================================================================
                         ROBUSTNESS CHECKS
================================================================================

The analysis includes 6 robustness checks to validate findings:

1. Alternative Clustering (by year instead of country)
   → Tests if correlation structure matters

2. Two-Way Clustering (by country AND year)
   → Most conservative standard errors

3. Stable Treatment (exclude switchers)
   → Tests if results driven by countries that flip-flop

4. Placebo Test (lead effects)
   → Future democracy changes shouldn't predict current data
   → If significant: suggests reverse causality problem

5. Lagged Dependent Variable
   → Controls for persistence in data missingness
   → Tests if effects are beyond autocorrelation

6. Income-Level Heterogeneity
   → Separate effects for Low, Lower-Middle, Upper-Middle, High income
   → Tests if effects concentrated in poor vs rich countries

================================================================================
                   INTERPRETING YOUR RESULTS
================================================================================

STRONG SUPPORT FOR HYPOTHESIS (Backsliding harms data availability):

✓ TWFE backsliding coefficient > 0 and significant (p < 0.05)
✓ TWFE backsliding coefficient > democratization coefficient
✓ Wald test rejects equality (p < 0.05)
✓ C-S overall ATT > 0 and significant
✓ C-S pre-treatment effects ≈ 0 (parallel trends hold)
✓ C-S post-treatment effects increase over time
✓ Categorical: Large backsliding > Moderate backsliding > Stable
✓ Robust across all specifications

MODERATE SUPPORT:

~ Some approaches significant, others not
~ Effects present but small magnitude
~ Significant only for specific SDGs (e.g., governance indicators)
~ Effects concentrated in low-income countries only

WEAK/NO SUPPORT:

✗ Coefficients near zero, not significant
✗ C-S pre-treatment effects significant (parallel trends violated)
✗ Large standard errors, wide confidence intervals
✗ Signs flip across robustness checks
✗ Placebo test significant (reverse causality concerns)

================================================================================
                      KEY QUESTIONS TO ANSWER
================================================================================

1. MAGNITUDE: How big is the effect?
   → Compare coefficient to mean of outcome variable
   → Calculate % change: (coef / mean) × 100
   → Example: If coef = 0.05 and mean = 0.50, that's 10% increase

2. SIGNIFICANCE: Is it statistically reliable?
   → Check p-values < 0.05
   → Check confidence intervals don't include zero
   → Robust across specifications?

3. ASYMMETRY: Is backsliding worse than democratization?
   → Compare |β₁| vs |β₂| in TWFE
   → Check Wald test p-value
   → Visual inspection: Are red dots further from zero than blue?

4. DYNAMICS: How do effects evolve?
   → C-S event study: Do effects grow over time?
   → Or immediate shock that persists?
   → Or delayed effects?

5. HETEROGENEITY: Who is affected most?
   → Income-level models: Poor vs rich countries?
   → Categorical: Only large changes matter?
   → Specific SDGs: Governance vs health vs environment?

6. CAUSALITY: Can we make causal claims?
   → C-S parallel trends hold?
   → Placebo test passes?
   → Theoretical mechanism plausible?
   → Alternative explanations ruled out?
